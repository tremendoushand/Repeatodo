# Repeatodo 사용자 가이드

Repeatodo는 매일·매주·매월 반복하는 할 일을 한 번의 탭으로 체크하고, 얼마나 잘 지켰는지 한눈에 보는 앱입니다. 회원가입 없이 바로 쓸 수 있어요.

## 1. 처음 시작하기

1. 앱을 처음 열면 **알림 권한**을 물어봐요. 허용해야 할 일 알림을 받을 수 있어요.
2. 기본 카테고리 4개(건강, 집안일, 업무, 자기계발)가 만들어져 있어요. 이름과 색은 언제든 바꿀 수 있어요.
3. 오른쪽 아래 **+** 버튼을 눌러 첫 할 일을 추가해 보세요.

## 2. 할 일 추가하기

| 항목 | 설명 |
|---|---|
| 제목 / 메모 | 할 일 이름과 짧은 메모 |
| 카테고리 | 색으로 구분돼요. 없음도 가능 |
| 반복 | **매일**, **매주**(요일 지정 또는 *주중 아무 때나 1번*), **매월**(날짜 지정, *말일*, 또는 *월중 아무 때나 1번*) |
| 알림 시간 정하기 | 켜면 그 시간에 따로 알려줘요. 끄면 설정의 ‘모아서 알림’ 시간에 다른 일과 함께 알려줘요 |
| 한 번에 N회 | 예: 물 마시기 하루 8회. 탭할 때마다 1회씩 올라가요 |
| 총 반복 횟수 | 예: 30일 챌린지. 다 채우면 ‘끝난 할 일’로 옮겨져요 |
| 시작일 | 이날부터 반복이 시작돼요 |
| 캘린더에 표시 | 설정에서 캘린더 연동을 켜면 폰 캘린더에 반복 일정으로 보여요 |

> 31일처럼 없는 날짜를 고르면, 그 날이 없는 달에는 마지막 날에 해요.

## 3. 오늘 화면

- 오늘 해야 할 일과, ‘이번 주 안에’·‘이번 달 안에’ 할 일이 나뉘어 보여요.
- **탭하면 완료**, 한 번 더 탭하면 취소예요. 여러 번 해야 하는 일은 탭할 때마다 숫자가 올라가요.
- **길게 누르면** 편집 화면이 열려요.
- 2번 이상 연속으로 지키면 🔥 연속 기록이 보여요.

## 4. 대시보드

- 위쪽에서 **주간 / 월간**을 고르고, 화살표로 이전·다음 기간을 볼 수 있어요. 가운데 날짜를 누르면 오늘로 돌아와요.
- **주간**: 할 일마다 요일별로 표시돼요.
  - 꽉 찬 동그라미: 완료 · 빨간 테두리: 놓침 · 색 테두리: 오늘 할 일 · 회색 테두리: 앞으로 할 일
- **월간**: 달력 색이 진할수록 그날 할 일을 많이 끝낸 날이에요. 아래에 할 일별 달성률이 나와요.
- 달성률은 지나간 날과 이미 완료한 날만 계산해요. 아직 안 끝난 오늘은 달성률을 깎지 않아요.

## 5. 알림

- **개별 알림**: 알림 시간을 정한 할 일은 그 시간에 알려줘요. 알림의 **완료** 버튼으로 앱을 열지 않고 바로 체크할 수 있어요.
- **모아서 알림**: 알림 시간을 정하지 않은 일은 설정의 ‘모아서 알림 시간’(기본 오전 8시)에 아직 안 한 것만 묶어서 알려줘요. 시간은 여러 개 추가할 수 있고, 시간을 눌러서 지울 수 있어요.
- 이미 끝낸 일은 알리지 않아요.
- 설정에 ‘정확한 시간 알림’ 경고가 보이면 **허용**을 눌러 주세요. 허용하지 않으면 알림이 몇 분 늦을 수 있어요.

## 6. 카테고리

할 일 탭 오른쪽 위 아이콘 → 카테고리 화면에서 추가·이름 변경·색 변경·순서 변경·삭제를 할 수 있어요. 카테고리를 지워도 할 일은 남아요.

## 7. 캘린더 연동

1. 설정 → **기기 캘린더에 할 일 표시**를 켜고 캘린더 권한을 허용해요.
2. 표시할 캘린더(예: 내 구글 캘린더)를 골라요.
3. 할 일 편집에서 **캘린더에 표시**를 켠 일이 반복 일정으로 등록돼요.

- 할 일을 바꾸면 일정도 바뀌고, 지우면 일정도 지워져요.
- 캘린더 앱에서 일정을 직접 고치면 다음 변경 때 Repeatodo 내용으로 덮어써져요.
- 연동을 끄면 Repeatodo가 만든 일정이 모두 지워져요.

## 8. 구글 드라이브 동기화

폰을 바꾸거나 여러 기기에서 쓸 때 데이터가 이어지게 해요.

1. 설정 → **구글 계정 연결**을 누르고 계정을 고른 뒤 허용해요.
2. **자동 동기화 주기**(수동, 1시간, 6시간, 12시간, 하루)를 골라요.
3. **Wi-Fi에서만 자동 동기화**를 켜면 모바일 데이터로는 자동 동기화하지 않아요. ‘지금 동기화’ 버튼은 언제든 바로 동기화해요.

- 데이터는 드라이브의 **앱 전용 숨김 공간**에 저장돼요. 내 드라이브 파일 목록에는 보이지 않고, 앱도 다른 파일을 볼 수 없어요.
- 두 기기에서 같은 할 일을 바꿨다면 더 나중에 바꾼 쪽이 남아요.
- 저장된 데이터를 지우려면 drive.google.com → 설정 → 앱 관리 → Repeatodo → ‘숨겨진 앱 데이터 삭제’를 누르세요.

## 9. 백업과 복원

설정 → 데이터에서 **백업 파일 만들기**로 JSON 파일을 저장하고, **백업 불러오기**로 다시 불러올 수 있어요. 불러오면 지금 데이터와 합쳐져요(같은 항목은 더 최근 것이 남아요). 안드로이드 기본 백업에도 포함돼요.

## 10. 자주 묻는 질문

- **알림이 안 와요.** 설정 화면 맨 위 경고가 있는지 확인하세요. 일부 휴대폰(삼성 등)은 배터리 최적화 때문에 알림이 늦을 수 있어요. 휴대폰 설정 → 애플리케이션 → Repeatodo → 배터리 → ‘제한 없음’으로 바꾸면 좋아요.
- **‘이번 주’는 언제부터인가요?** 월요일부터 일요일까지예요.
- **할 일을 잠깐 쉬고 싶어요.** 지금은 삭제하거나 시작일을 미래로 바꾸면 돼요.
- **동기화 오류가 떠요.** ‘구글 계정 다시 연결’을 눌러 보세요. 그래도 안 되면 인터넷 연결을 확인해 주세요.
