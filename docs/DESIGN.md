# Repeatodo 설계

반복되는 할 일(매일·매주·매월)을 한 번의 탭으로 체크하고, 주간·월간으로 돌아보는 개인용 안드로이드 앱입니다.

## 1. 화면 구성

하단 탭 4개로 단순하게 구성합니다.

| 탭 | 내용 |
|---|---|
| **오늘** | 오늘 해야 할 일 + "이번 주 안에", "이번 달 안에" 할 일. 상단에 오늘 진행률(예: 3/5). 체크박스 한 번 탭으로 완료, 다시 탭하면 취소. 여러 번 해야 하는 일(예: 물 3번)은 탭할 때마다 1씩 올라감 |
| **대시보드** | 주간/월간 전환, 이전·다음 기간 이동. 주간은 할 일 × 요일 표, 월간은 달력 형태의 날짜별 달성률 색상 + 할 일별 달성률 막대. 카테고리별 달성률 |
| **할 일** | 전체 할 일 목록(카테고리별 묶음, 카테고리 필터 칩). + 버튼으로 추가, 탭해서 편집. 카테고리 관리 진입 |
| **설정** | 알림, 일반, 캘린더 연동, 구글 드라이브 동기화, 데이터 관리, 정보 |

**할 일 편집 화면**: 제목, 메모, 카테고리, 반복(매일/매주/매월), 요일 선택 또는 "주중 아무 때나", 날짜 선택 또는 "월중 아무 때나"/"말일", 알림 시간(선택), 한 번에 몇 회(선택), 총 반복 횟수(선택, 다 채우면 자동 종료), 시작일, 캘린더에 표시.

## 2. 반복 규칙

| 종류 | 세부 | 예시 |
|---|---|---|
| 매일 | 매일 | 영양제 먹기 |
| 매주 | 특정 요일(복수 선택) 또는 주중 아무 때나 1번 | 월·수·금 운동 / 이번 주에 한 번 분리수거 |
| 매월 | 특정 날짜(1~31일, 말일) 또는 월중 아무 때나 1번 | 25일 카드값 확인 / 이번 달에 한 번 대청소 |

- 31일처럼 없는 날짜는 그 달의 말일로 맞춥니다.
- **반복 횟수 옵션**은 두 가지로 해석될 수 있어 둘 다 넣었습니다.
  - *한 번에 몇 회*: 하루(또는 그 회차)에 N번 해야 완료. 예: 물 마시기 하루 8번.
  - *총 반복 횟수*: N번 완료하면 할 일이 자동으로 "완료됨" 보관함으로 이동. 예: 30일 챌린지.
- 한 주는 월요일부터 일요일까지로 계산합니다.

## 3. 알림

- **개별 알림**: 알림 시간을 정한 할 일은 해당 날짜 그 시간에 알림. 알림의 "완료" 버튼으로 앱을 열지 않고 체크.
- **모아서 알림**: 알림 시간을 정하지 않은 할 일은 설정의 "모아서 알림 시간"(기본 오전 8시, 여러 개 추가 가능)에 아직 안 한 일만 묶어서 한 번에 알림.
- 이미 완료한 일은 알리지 않습니다. 재부팅·시간대 변경 후 자동 재예약.
- 정확한 시각 알림 권한(Android 12+)을 허용하지 않으면 몇 분 늦을 수 있어 설정에서 허용 버튼을 제공합니다.

## 4. 데이터 구조 (Room DB가 원본)

- `categories`: id, 이름, 색상, 정렬순서, updatedAt, deleted
- `tasks`: id, 제목, 메모, categoryId, 반복종류, 요일비트, 월날짜, 알림시간, 회차당 횟수, 총 반복 횟수, 시작일, 캘린더표시, 보관여부, 정렬순서, updatedAt, deleted
- `completions`: id(=taskId+회차), taskId, 회차날짜, 횟수, updatedAt, deleted
- `calendar_links`: taskId → 기기 캘린더 이벤트 id (기기마다 다르므로 동기화하지 않음)
- 설정은 DataStore에 저장.

## 4-1. 화면 사용 흐름

- 오늘 탭에서 할 일을 **탭하면 완료**, 한 번 더 탭하면 취소. **길게 누르면 편집**.
- 할 일 탭에서는 전체 목록을 보고 눌러서 편집, 오른쪽 위 아이콘으로 카테고리 관리.

모든 id는 UUID, 삭제는 "삭제 표시"(tombstone)로 남겨 여러 기기 동기화 시 충돌을 막고, 90일 지나면 정리합니다.

## 5. 아키텍처

- Kotlin, Jetpack Compose, Material 3(안드로이드 12+ 배경화면 색상 테마), 단일 Activity + Navigation Compose.
- 계층: `domain`(반복 계산 등 순수 로직, 단위 테스트) → `data`(Room, DataStore, Repository) → `ui`(화면별 ViewModel + StateFlow).
- 의존성 주입은 라이브러리 없이 `AppContainer` 하나로 (작은 앱에 가장 단순).
- 알림: AlarmManager + BroadcastReceiver. 동기화: WorkManager 주기 작업(Wi-Fi 전용/모바일 데이터 허용 조건).
- minSdk 26(Android 8.0), targetSdk 36. 패키지 이름 `com.tremendoushand.repeatodo`.

## 6. 로그인과 데이터 관리

- **회원가입·로그인 없음.** 앱은 바로 쓸 수 있고 데이터는 폰 안에 저장됩니다.
- 구글 계정은 드라이브 동기화를 켤 때만 연결합니다(권한은 앱 전용 숨김 폴더 `appDataFolder` 하나만 요청 → 사용자의 다른 드라이브 파일은 볼 수 없음).
- 동기화: 드라이브의 `repeatodo-sync.json` 한 파일과 로컬 DB를 항목별 "최근 수정 우선"으로 병합 후 양쪽에 반영. 주기(수동/1·6·12·24시간), Wi-Fi 전용 여부 선택, "지금 동기화" 버튼.
- 수동 백업: JSON 내보내기/가져오기(파일 선택 창), 안드로이드 기본 백업도 허용.

## 7. 캘린더 연동

- 설정에서 켜고 표시할 기기 캘린더(예: 구글 캘린더 계정)를 고르면, "캘린더에 표시"가 켜진 할 일이 반복 일정(RRULE)으로 등록됩니다.
- 할 일을 바꾸거나 지우면 일정도 함께 바뀌고 지워집니다. 구글 클라우드 설정이 필요 없습니다(기기 캘린더 API 사용).

## 8. 제안(추가/단순화)

- 추가: 알림에서 바로 완료, "이번 주/이번 달 안에" 유연한 반복, 연속 달성(streak) 표시, 카테고리 기본 4개 제공(건강·집안일·업무·자기계발), 다크 모드.
- 나중에 고려: 홈 화면 위젯, 할 일 순서 드래그, 일시정지(휴가 모드).
- 단순화: 로그인 화면을 없애고 구글 연결은 동기화 전용으로 한정.
