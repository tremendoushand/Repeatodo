# Repeatodo 개인정보처리방침

시행일: 2026년 10월 16일

Repeatodo(이하 "앱")는 사용자의 개인정보를 소중히 여기며, 필요한 최소한의 정보만 다룹니다.

## 1. 수집하는 정보

앱은 개발자의 서버로 어떤 정보도 보내지 않으며, 별도의 회원가입이나 광고·분석 도구를 사용하지 않습니다.

앱이 사용자의 기기 안에 저장하는 정보:
- 사용자가 입력한 할 일, 메모, 카테고리, 완료 기록, 앱 설정

## 2. 선택 기능에서 사용하는 정보

- **구글 드라이브 동기화(선택)**: 사용자가 직접 켠 경우에만 위 데이터를 사용자 본인의 구글 드라이브 "앱 전용 공간(appDataFolder)"에 저장합니다. 앱은 `drive.appdata` 권한만 요청하며, 사용자의 다른 드라이브 파일을 읽거나 쓸 수 없습니다. 데이터는 구글의 개인정보처리방침에 따라 보관됩니다.
- **캘린더 연동(선택)**: 사용자가 켠 경우에만 기기 캘린더 목록을 읽고, 사용자가 고른 캘린더에 Repeatodo 할 일을 일정으로 추가·수정·삭제합니다. 다른 일정은 읽거나 바꾸지 않습니다.
- **알림**: 할 일 알림을 보여주기 위해 알림 권한을 사용합니다.

## 3. 제3자 제공

앱은 사용자의 정보를 누구에게도 판매하거나 제공하지 않습니다.

## 4. 데이터 삭제

- 앱을 삭제하면 기기 안의 데이터가 모두 삭제됩니다.
- 드라이브에 저장된 데이터는 drive.google.com → 설정 → 앱 관리 → Repeatodo → "숨겨진 앱 데이터 삭제"로 지울 수 있습니다.
- 캘린더 일정은 앱 설정에서 캘린더 연동을 끄면 삭제됩니다.
